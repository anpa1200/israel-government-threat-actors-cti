# Score C: Watchlist And Corroboration Queue

Use this folder for leads that are relevant but not yet strong enough for production attribution, blocking, or executive claims.

## Watchlist Topics

| Topic | Why Track | Required Corroboration |
| --- | --- | --- |
| New Handala public claims | Israel-focused hack-and-leak and destructive claims can create communications risk. | Confirm victim statement, vendor report, government advisory, or local telemetry. |
| Cyber Toufan claims | Public claims may affect public confidence and executive attention. | Require independent technical evidence before treating as confirmed compromise. |
| Anonymous Telegram leak channels | May publish claimed Israeli government or supplier data. | Verify data authenticity, age, ownership, and lawful handling constraints. |
| New Iran-linked hacktivist OT claims | OT targeting claims can indicate exposure patterns even when attribution is unclear. | Validate exposed assets, device fingerprints, access logs, and official advisories. |
| Social-media-only IOC lists | Some lists mix stale, false, or recycled infrastructure. | Re-score IOCs with source provenance, passive DNS, sandbox, and local telemetry before action. |

## Handling

- Do not copy leaked data or personal data into this repository.
- Do not cite watchlist material as fact.
- Promote items to Score B or Score A only after source quality improves.
